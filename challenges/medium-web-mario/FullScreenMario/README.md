# Super Mario Bros — Web Edition

A tiny browser port of the classic, with a small fan-blog of Mario articles
bolted on. Press **START** on the home page to play, or read the articles.

## Controls

- Move: Arrows / WASD
- Jump: Up / W
- Run / Fire: Shift
- Pause: P, Mute: M
